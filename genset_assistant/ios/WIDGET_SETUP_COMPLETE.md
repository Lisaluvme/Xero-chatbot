## 🔄 **How It Works:**

1. **Data Updates in Flutter** → `genset_provider.dart` calls `_updateWidgetData()`
2. **Sends via MethodChannel** → `watch_service.dart` → Native iOS
3. **Stores in Shared Defaults** → `AppDelegate.swift` saves to `UserDefaults(suiteName:)`
4. **Widget Reads Data** → Extension pulls from shared defaults
5. **Displays on Home Screen** → Native SwiftUI widget with beautiful design
