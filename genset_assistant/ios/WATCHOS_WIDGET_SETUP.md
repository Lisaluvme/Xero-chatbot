## 🚀 **Setup Instructions:**

### **Step 1: Add watchOS Widget Extension Target**

In Xcode, add the new target (you should have **Widget Extension** showing):

```
📱 Platform:     watchOS
🎨 Category:     Extension
🚀 Template:     Widget Extension  ← SELECT THIS!
⚙️  Name:        GensetWatchWidget
📝 Language:     SwiftUI
✅ Include:     ✓ Live Activity
✅ Include:     ✓ Intent Configuration
```

---

### **Step 2: Copy Ready Files**

Replace the Xcode-generated template files with the created ones:

**Replace: `GensetWatchWidget.intentdefinition`**
- Copy the content from `genset_assistant/ios/GensetWatchWidget/GensetWatchWidget.intentdefinition`

**Replace: `GensetWatchWidget.swift`**
- Copy the complete code from `genset_assistant/ios/GensetWatchWidget/GensetWatchWidget.swift`

---

### **Step 3: Configure Entitlements**

Add **App Groups** to ALL targets:
- **iOS Main App**: `group.com.mega.gensetassistant`
- **Watch App** (if you have one): `group.com.mega.gensetassistant`
- **Watch Widget Extension**: `group.com.mega.gensetassistant`

---

### **Step 4: Add to Watch Face**

On your Apple Watch:

```
1. Press and hold main watch face
2. Tap "Edit"
3. Tap on complication slot
4. Scroll to find "Genset Monitor"
5. Select and configure
```

## ⚙️ **Widget Features:**

- ✅ **Accessory Circular**: Simple ON/OFF status with color coding
- ✅ **Accessory Rectangular**: Full genset details on Apple Watch
- ✅ **Live Updates**: Syncs with iPhone app data automatically
- ✅ **Battery Efficient**: Uses shared UserDefaults, minimal battery impact
- ✅ **Always Available**: Works even when iPhone app isn't running
- ✅ **Offline Capable**: Uses cached data when network unavailable

---

## 🔌 **How Widgets Work:**

1. **iPhone App** loads genset data → updates shared UserDefaults
2. **watchOS Widget** reads from shared defaults → displays live data
3. **Complications** show simple status → tap for detailed widget
4. **Auto-refresh** every 10 minutes (watchOS optimized)
